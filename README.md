# GRAIN & LIGHT — V5
### Analog Photography Supply · Film · Cameras · Lenses · Darkroom

**GRAIN & LIGHT** is a premium storefront concept celebrating analog photography: the ritual of loading film, the feel of mechanical cameras, and the thoughtful accessories that make each frame personal.

> Real moments. Last longer.

## V5 — What changed
- Rebuilt the main hero area around a dedicated cinematic photography crop instead of the old awkward close-up.
- Added a richer storefront structure: benefit strip, four image-led categories, curated product catalog, brand story, field notes, newsletter demo, FAQs, support, and footer navigation.
- Each of the eight products uses its own dedicated image file; product images are not repeated as the same source image across all product cards.
- Added brand labels, better category organization, product search, filters, sorting, cart quantity controls, and subtotal calculation.
- Updated sample prices to more plausible illustrative ranges.
- Added mobile navigation, responsive layouts, semantic labels, visible focus styles, and clear demo notices.

## Run locally
Open `index.html` in a modern browser, or run `python -m http.server 8000` from the project folder and visit `http://localhost:8000`.

## Deploy to GitHub Pages
1. Upload the project files to the `main` branch.
2. In repository Settings → Pages, select `main` and `/ (root)`.
3. Wait for deployment and test the published page on desktop and mobile.

Expected project URL for owner `media-shake`: `https://media-shake.github.io/grain-and-light/` (available after Pages is enabled).
